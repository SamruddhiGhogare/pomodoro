#  Pomodoro Timer

A beautiful and functional Pomodoro timer web application with task management capabilities.

## Features
- 25/5/15 minute Pomodoro timer
- Task management system
- Beautiful neumorphic design
- Responsive layout
- Sound notifications

## Setup
1. Clone this repository
2. Open `index.html` in your web browser
3. Start managing your time effectively!

## Usage
- Click the play button to start the timer
- Use the mode buttons to switch between Pomodoro, Short Break, and Long Break
- Add tasks using the input field
- Mark tasks as complete or delete them as needed

## Development
To modify the application:
1. Edit `index.html` for structure
2. Edit `styles.css` for styling
3. Edit `script.js` for functionality
